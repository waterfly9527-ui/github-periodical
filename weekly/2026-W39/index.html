风险

编辑分析：本地并不自动等于安全。屏幕、音频、文件和长期记忆会形成更高密度的敏感数据面；硬件/模型格式仍碎片化；常驻 Agent 一旦拿到写权限，故障半径会从“答错”扩大到“做错”。另外，仓库显示 NOASSERTION 时不能解释成“没有许可证限制”，采用前必须直接核验仓库 License。

团队采用路径

  1. 先用 llamafile 或设备原生运行时验证离线推理的成本、质量与运维。
  2. 按目标终端选择 GenieX 或 MLX-VLM，补齐端侧加速与多模态。
  3. 只有在数据保留、删除、访问策略明确后，再接 screenpipe / Meetily 这类高密度个人上下文。
  4. 最后引入 Hermes / Olares 常驻执行层；默认最小权限，写操作隔离并保留人工确认。
